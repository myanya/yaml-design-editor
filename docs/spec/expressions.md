- 読む実装: semantic-core/schema/QuerySpec.kt の QueryWhere
- 実装する機能（[FEATURES.md](../FEATURES.md) の ID）: V-09

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `of` |  | 束縛の名前 | いまの要素（型の検査の中） | 値を読むノード。 |
| `path` |  | パスの文字列 |  | 値の場所（要素からの相対パス）。 |
| `equals` |  | 値 |  | 値が指定の値と等しいこと。 |
| `notEquals` |  | 値 |  | 値があり、どの出現の値も指定の値でないこと。値が無ければ成り立ちません。 |
| `exists` |  | 真偽値 |  | true は項目が書かれていること、false はどの出現にも書かれていないこと。 |
| `empty` |  | 真偽値 |  | false は中身のある値が書かれていること、true はどの出現にも中身のある値が無いこと（書かれていない・空文字・null・空の配列・空の object を空とみなします）。 |
| `oneOf` |  | 値の配列 |  | 値が選択肢のどれかであること。 |

| `includesAny` |  | 値か、値の配列 |  | 配列の値が、そのどれかを要素に持つこと。 |

| `not` |  | 条件 |  | 条件が成り立たないこと。値が無く判定できないときは成り立ちません。 |
| `or` |  | 条件の配列 |  | どれかが成り立つこと。同じ束縛の条件どうしを並べます。 |

## 値の式

値を計算する式。決まった値（文字・数・真偽値）はそのまま書け、それ以外は下の語を 1 つ持つ object で書きます。{パス} を含む文字列は format の短い書き方です。検査の外（スキーマの値の式・ビューの列・each の value）では「いまの要素」があるので of を省けます。値が得られないときは「得られない」になり、それを使う計算も得られません。

- 読む実装: semantic-core/schema/ValueExpr.kt の parse
- 実装する機能（[FEATURES.md](../FEATURES.md) の ID）: S-23・X-09

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `of` |  | 束縛の名前 | いまの要素（検査の外） | 読み出し {of, path} の、値を読む要素。 |
| `path` |  | パスの文字列 |  | 読み出しの、値の場所（要素からの相対パス）。その場所の項をそのまま返します。[*] を書くと、合う場所の値を並べた配列になります。 |
| `in` |  | {schemaId, fileGlob} | 同じ ID が書かれたすべての文書 | 読み出しの、値を読む文書。 |
| `via` |  | 参照の項目か、その配列 |  | 読み出しの前に、その要素に書かれた参照を 1 段たどり、相手の要素から読みます。配列は段を重ねます。各段で参照がちょうど 1 本のとき相手が決まります。検査の外でだけ書けます。 |
| `value` |  | 値 |  | 決まった値。値が無ければ「得られない」です。each と一緒のときは、各要素に当てる式です。 |
| `format` |  | 値の式（{パス} を含む文字列） |  | 文字列の中の {パス} を、値で置き換えます。置き換えられない穴があれば「得られない」です。 |
| `scopes` |  | {of, in, via} の配列 | いまの要素（検査の外） | format の穴の値を探す入れ物。近い順に探します。 |
| `with` |  | 穴の名前 → 値の式 のマップ |  | format の穴に、式で計算した値を入れます。 |
| `map` |  | 値の式 |  | 辞書での置き換え。using と一緒に書きます。辞書に無い値はそのままです。 |
| `using` |  | 元の値 → 先の値 のマップ |  | map の辞書。 |
| `first` |  | 値の式の配列 |  | 最初に得られた値。 |
| `length` |  | 値の式 |  | 文字数。 |
| `upper` |  | 値の式 |  | 大文字にします。 |
| `lower` |  | 値の式 |  | 小文字にします。 |
| `number` |  | 値の式 |  | 数として読み直し、表記をそろえます（12.0 → 12）。数として読めなければ「得られない」です。 |
| `year` |  | 値の式 |  | 日付か日時の年（数）。 |
| `month` |  | 値の式 |  | 日付か日時の月（1〜12）。 |
| `day` |  | 値の式 |  | 日付か日時の日。 |
| `yearMonth` |  | 値の式 |  | 日付か日時の年月（2026-10 の形の文字）。月ごとの集計の鍵に使います。 |
| `weekStart` |  | 値の式 |  | その日を含む週の月曜の日付。週ごとの集計の鍵に使います。 |
| `extract` |  | [値の式, 正規表現] |  | 文字の一部を取り出します。最初に合った部分で、正規表現に括弧があれば 1 つ目の括弧の中身です。合わなければ「得られない」です。 |
| `add` |  | 値の式の配列（2 つ以上） |  | 足し算。 |
| `subtract` |  | [値の式, 値の式] |  | 引き算。 |
| `multiply` |  | 値の式の配列（2 つ以上） |  | 掛け算。 |
| `divide` |  | [値の式, 値の式] |  | 割り算。0 で割ると「得られない」です。 |
| `daysBetween` |  | [始まり, 終わり] |  | 日付の差の日数（終わり − 始まり）。 |
| `sum` |  | 配列を返す式（{path} は短い書き方） |  | 配列の合計。 |
| `min` |  | 配列を返す式 |  | 配列の最小。比べ方は type で決めます。 |
| `max` |  | 配列を返す式 |  | 配列の最大。比べ方は type で決めます。 |
| `count` |  | 配列を返す式 |  | 配列の件数。 |
| `type` |  | number・date・time・datetime のどれか | 読んだ項目の型から決めます | 集計の比べ方。sum に日付の種類は書けず、count には書けません。 |
| `all` |  | {of, in, path} か {from, match, where, also, of, in, path} |  | 集合から配列へ。同じ起点のすべての解にわたって、束縛した要素（重なりは 1 つ）の path の値を並べます。path を省くと ID の配列です。match を書くと、起点を固定したクエリの解から並べます。 |
| `each` |  | 配列を返す式 |  | 要素ごとの式。各要素を「いまの要素」として value を評価し、配列にします。 |
| `refCount` |  | {of, dir, relation, via} |  | その要素から出ていく・その要素へ入ってくる参照の本数。同じ相手への参照が 2 本あれば 2 と数えます。 |
| `occurrenceCount` |  | {of, schema, fileGlob, role, distinct} |  | その ID が書かれている場所のうち、指定に合うものの数。role は defining か detail です。distinct: type を書くと、場所の数ではなくエンティティ型の種類の数です。 |

## 文書の指定

値を読む文書・参照が書かれた文書を指す object（値の式と edge の in、format の scopes の in）。schemaId か fileGlob のどちらかは必要で、両方書くと両方に合う文書です。

- 読む実装: semantic-core/schema/ValueExpr.kt の parseSelector
- 実装する機能（[FEATURES.md](../FEATURES.md) の ID）: S-23・X-09

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `schemaId` |  | スキーマ ID |  | 文書のスキーマ。 |
| `fileGlob` |  | glob の文字列 |  | 文書のファイル。 |
