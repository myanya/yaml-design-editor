# スキーマの項目定義

スキーマの項目 1 つの定義に書ける語（キー）と、`type` に書ける基底の種類の一覧。今の実装が読む語を書いたもので、使い方の説明は [manual/schema.md](../manual/schema.md) にある。
**原本は [devtrack/](../../devtrack/README.md) の `spec/`**（1 語 1 ファイルの YAML）。足す・直すときは YAML を書き、`./gradlew devtrackDocs` で作り直す。

スキーマの項目 1 つの定義。文書のルート（root）・object の子（fields の要素）・array の要素（item）・map の値（value）・型の定義（definitions の値）・操作の受け取る値（params の要素）に、同じ形で再帰的に書きます。

- メタスキーマ: builtin-schemas/schema.yaml の definitions.field
- 読む実装: semantic-core/schema/SchemaTreeParser.kt の parseField
- 実装する機能（[FEATURES.md](../FEATURES.md) の ID）: S-02・S-24

## 基底の種類

`type` に書ける基底の種類。これ以外の名前は型の名前（組込みの型 `text`・`line`・`word` と、`definitions` に定義した型）で、解決すると末端がこのどれかになる。

### 表現の基底（スカラー）

| type | 値の形 | 意味 |
|---|---|---|
| `boolean` | true か false | 真偽値。 |
| `enum` | values に並べた値のどれか | 選択肢。values が必須です。保存する値は value で、label は表示だけに使います。 |
| `int` | 整数 | 整数。 |
| `number` | 数 | 数（小数を書けます）。 |
| `string` | 文字列 | 自由な文字列。複数行を保証するのは組込みの型 text、1 行は line、1 語は word です。 |

### 決まった形の文字（日付・時刻・ファイルの場所）

| type | 値の形 | 意味 |
|---|---|---|
| `date` | YYYY-MM-DD | 年月日。形に合っていても、存在しない日付（2026-02-30）は誤りです。 |
| `datetime` | YYYY-MM-DD HH:MM（秒は任意。区切りは空白か T） | 日時。存在しない日時は誤りです。 |
| `file` | ファイルの場所の文字列 | ファイルの場所。ワークスペースのルートからの相対、./ で始めて文書からの相対、または絶対で書きます。存在と許可は検査が確かめます。 |
| `time` | HH:MM か HH:MM:SS | 時刻。存在しない時刻は誤りです。 |

### 識別と参照

| type | 値の形 | 意味 |
|---|---|---|
| `id` | 空白を含まない文字列 | 論理要素の ID。この項目を持つ要素が ID 索引に載ります。同じ ID を別の文書に書くと、同じ要素の別の側面として扱います。 |
| `ref` | 参照先の ID（空白を含まない文字列） | ほかの要素の ID への参照。索引で解決し、解決できない参照は検証の指摘になります。 |

### 構造

| type | 値の形 | 意味 |
|---|---|---|
| `array` | 配列 | 配列。item（要素の定義）が必須です。 |
| `map` | 任意のキーのマップ | 任意のキーの連想配列。value（値の定義）が必須です。 |
| `object` | 決まったキーのマップ | オブジェクト。fields（子の項目）が必須です。 |

### 制約なし

| type | 値の形 | 意味 |
|---|---|---|
| `any` | 任意の値 | 任意の値。必須かどうか以外は検証しません。1 つの型で表せない場所を明示するために使います。 |

## 語

「書ける型」は、その語を書ける項目の基底の種類。「すべて」は種類を限らない。同じ語でも、種類によって値の形と意味が変わるものは行を分ける。

### 形

| 語 | 書ける型 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `$ref` | すべて | 定義の名前の文字列 |  | definitions の中の名前付きの定義を、この項目の定義として使います。別のモジュールの定義は モジュールID#名前 と書きます。再帰する形もこれで書きます。 |
| `cases` | `enum` | 値 → 項目定義の配列 のマップ |  | 選択肢の値ごとに、親の object へ足す兄弟の項目。 |
| `fields` | `object` | 項目定義の配列 |  | 子の項目の一覧。object では必須です。型の名前（オブジェクト型）を使う側では、定義に無いキーは末尾に足され、定義にあるキーは同じ項目を狭めます。 |
| `fields` | `ref` | 項目定義の配列 |  | 参照に添える属性の宣言。書いたときだけ、参照を {to, 属性…} の object の形で書けます。 |
| `item` | `array` | 項目定義 |  | 配列の要素の定義。array では必須です。 |
| `key` | すべて | 文字列 |  | 親の object の中でのキーの名前。文書のルート・配列の要素・map の値・型の定義では書きません。 |
| `ref` | すべて | 定義の名前の文字列 |  | $ref の別の書き方です。（別の書き方） |
| `type` | すべて | 基底の種類の名前か、型の名前 | string | 項目の型。基底の種類か、型の名前（組込みの型 text・line・word、definitions に定義した型、別のモジュールの型は モジュールID#名前）を書きます。型の名前を書くと定義の決まりを引き継ぎ、ここに書く決まりは狭めるだけです。 |
| `value` | `map` | 項目定義 |  | マップの値の定義。map では必須です。 |
| `values` | `enum` | 配列 |  | 選択肢の一覧。要素は文字列か、{value, label, description} の形です。検証は value で行い、label と description は表示だけに使います。 |

### 必須と値の決まり

| 語 | 書ける型 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `allowSingle` | `array` | true か false |  | true にすると、要素が 1 つだけのとき、並びにせずそのまま書けます（tags: a は tags: [a] と同じ）。並びでない値は要素 1 つとして読み、要素の決まり（型・形式・参照）で確かめます。場所は項目そのもので [0] を付けないので、パスの [*] は並びの書き方にだけ合います。型に書けば使う側に引き継がれます。 |
| `extensions` | `file` | 拡張子の配列 | 制限しません | 許す拡張子の一覧（ドットなし。大文字と小文字は区別しません）。<br>型に書けば引き継がれ、使う側が書けば狭めます。 |
| `max` | `int`・`number` | 数 |  | 値の上限。 |
| `maxLength` | `string` | 整数 |  | 文字数の上限。 |
| `min` | `int`・`number` | 数 |  | 値の下限。 |
| `minLength` | `string` | 整数 |  | 文字数の下限。 |
| `pattern` | `string` | 正規表現の文字列 |  | 値の全体がこの正規表現に一致すること。<br>型に書けば引き継がれ、使う側は狭めるだけです。 |
| `pattern` | `id` | 正規表現の文字列 |  | ID の全体がこの正規表現に一致すること。ID の採番の候補の元にもなります。<br>型に書けば引き継がれ、使う側は狭めるだけです。 |
| `pattern` | `date`・`time`・`datetime` | 正規表現の文字列 |  | 正準の形に加えて、さらに狭める形式。<br>型に書けば引き継がれ、使う側は狭めるだけです。 |
| `pattern` | `file` | 正規表現の文字列 |  | 場所の文字が一致すべき形式。<br>型に書けば引き継がれ、使う側は狭めるだけです。 |
| `required` | すべて | 真偽値 |  | true で必須。値が無いと検証のエラーになります。requiredFrom と一緒には書けません。 |
| `requiredFrom` | すべて | フェーズの名前の文字列 |  | スキーマの phases に並べたフェーズのうち、このフェーズ以降で必須になります。required と一緒には書けません。 |
| `unique` | `array` | true か、比べる項目のキーの配列 |  | 要素が重ならないこと。要素がスカラーなら true、object なら比べる項目のキーの一覧を書きます（複数書けばその組で比べます）。 |
| `unknownFields` | `object` | allow・warning・error のどれか | warning | スキーマに無いキーの扱い。allow は通知せず、warning は警告、error はエラーにします。 |

### 識別・参照・関係

| 語 | 書ける型 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `entity` | `object` | {type, defines, aspect, owns} |  | この object の要素がどのエンティティ型かの宣言。文書スキーマの entity より優先します。名前付きの型では、type を省くと定義の名前になります。defines: true は、この要素の出現がそのエンティティの定義であることを表します。 |
| `idPattern` | `ref` | glob の文字列か、その配列 |  | 参照先の ID を glob（* と ?）で限ります。複数書くと、どれかに合えばよい扱いです。 |
| `idPatterns` | `ref` | glob の文字列の配列 |  | 参照先の ID を限る glob を複数書きます（どれかに合えばよい）。 |
| `relation` | `ref` | 関係の名前の文字列 |  | 参照の関係の名前（例 implements）。参照の解決には影響せず、表示・クエリ・検査が線の名前として使います。 |
| `relation` | `array`・`map`・`object` | 関係の名前の文字列 | キーの名前 | この項目の中に書いた ID を持つ要素を、外側の ID を持つ要素が保有する関係の名前。 |
| `scope` | `ref` | {schemaIds, documentIds} |  | 参照先を探す範囲。schemaIds はスキーマ ID、documentIds は文書 ID で限ります（それぞれ文字列か配列。配列の中はどれかに合えばよい）。 |
| `target` | `ref` | entity か document | entity | 参照の相手の種類。document は文書そのものへの参照です。 |

### 値の式・自動の値・操作と検査

| 語 | 書ける型 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `auto` | すべて | created・updated・revision のどれか |  | 保存のときに自動で入る値の印。created は要素を新しく作ったとき、updated は要素の中身が変わって保存されるたびに、今の日付・時刻を入れます（date・time・datetime の項目に書く）。revision は保存のたびに保存済みの値に 1 を足します（int の項目に書く）。 |
| `constraints` | `object` | 検査の配列 |  | この object の要素ごとに評価する検査。1 件は {id, description, where, check か expect: absent, level, message} の形です。 |
| `expression` | すべて | 真偽値 |  | true にすると、この項目の値は値の式でもよくなります（{パス} を含む文字列か、式の object）。基底の種類が string の型にだけ書けます。どの項目が式かは、この印だけが決めます。 |
| `methods` | `object` | 操作の名前 → 定義 のマップ |  | この object の要素 1 つを受け手にする操作。予約の名前 create は新しい要素の中身 {label, params, build} で、ほかの操作は {label, description, params, do} の形です。 |
| `methods` | `array` | {insert: 追加の決まり} |  | 配列へ要素を足すときの決まり。書けるのは insert だけで、ID の採番（id）と、重複を見分ける項目（key）を書きます。 |

### 表示と編集のヒント

| 語 | 書ける型 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `default` | すべて | 任意の値 |  | 要素や文書を新しく作るときの初期値。 |
| `description` | すべて | 文章 |  | 項目の説明。フォームに表示します。 |
| `display` | `string` | multiline |  | 複数行の欄で編集します。見せ方だけで、値と検証は変えません。 |
| `display` | `int`・`number` | grouped |  | 桁区切りで見せます（45000 → 45,000）。見せ方だけで、値・検証・書き出しは変えません。 |
| `display` | `array`・`map` | table か list | 列の構成から自動で決めます | 一覧の表示の形。table は表の形に、list は縦並びに固定します。 |
| `format` | `int`・`number` | DecimalFormat のパターン |  | 画面で見せる形（例 ¥#,##0）。ファイルと編集中は素の数のままです。display: grouped より優先します。 |
| `format` | `date`・`time`・`datetime` | DateTimeFormatter のパターン |  | 画面で見せる形（例 yyyy年M月d日）。ファイルと編集中は正準の形のままです。 |
| `label` | すべて | 文字列 | キーの名前を表示します | フォームと一覧での表示名。 |
| `placeholder` | すべて | 文字列 |  | 値が空のときに、入力欄へ薄く出す案内。<br>型に書けば、その型を使う項目に引き継がれます。 |
| `role` | すべて | title か subtitle |  | この項目の値を、要素の 1 行要約のタイトル（title）か副題（subtitle）に使います。 |
| `rows` | `string` | 整数 |  | 複数行の欄の高さの目安（行数）。display: multiline の型で使います。 |
| `sample` | すべて | 任意の値 |  | プレビューのサンプルの YAML で、初期値が無いときに使う値。<br>型に書けば、その型を使う項目に引き継がれます。 |
