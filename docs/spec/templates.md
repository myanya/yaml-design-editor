## 変換のひな型の指示

ひな型は、出力の形をそのまま YAML で書いたものです。`$` で始まるキーを持つマップだけが指示で、それ以外は書いたとおりに出力します。値が得られない指示は「無い」になり、マップのキーごと出力から落ちます。文字列 $名前 は受け取った値で、繰り返しの中では $key・$index（0 始まり）・$position（1 始まり）を使えます。$$ は文字の $ です。

- 読む実装: semantic-core/schema/TransformDef.kt の TransformDef

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `$copy` |  | パス |  | その場所の値（部分木ごと）をそのまま写します。. は、いまの場所そのものです。 |
| `$format` |  | {パス} を含む文字列 |  | 文字のひな型を、その場所の値で埋めます。埋まらない穴があれば「無い」です。 |
| `$map` |  | ひな型 |  | 値を辞書（$using）で置き換えます。辞書に無い値はそのままです。 |
| `$first` |  | ひな型の配列 |  | 最初に得られた値。 |

| `$zip` |  | 名前 → パス のマップ |  | 並んだ配列を同じ番号で 1 行にまとめ、行ごとに組み立てて配列を作ります。長さが違えば長い方に合わせます。 |

| `$trim` |  | ひな型 |  | 前後の空白を落とし、続く空白を 1 つにまとめます（全角の空白も）。空なら「無い」です。 |
| `$case` |  | ひな型 |  | 名前の書き方をそろえます。書き方は $as に書きます。 |

| `$as` |  | 形の文字列 |  | 出力の形。$date では年月日の形（yyyyMMdd・yyyy-MM など）、$number では DecimalFormat の形（00・#,##0）、$case では名前の書き方です。 |

| `$bind` |  | 名前（英字で始まる。key・index・position は使えません） |  | 繰り返しの要素（$group ではまとまり）に名前を付け、中から $of で読めるようにします。 |
| `$flatten` |  | 真偽値 |  | $each の結果の配列を 1 段ならします。 |
| `$by` |  | ひな型 |  | $group のキー。要素を「いまの場所」にして計算します。キーが「無い」要素は、どのまとまりにも入りません。 |

## 名前を付けた組み立て（規則）

変換定義・生成の定義・レポートの rules の要素。同じ名前の規則を並べると、上から順に when を調べて、最初に合ったものを使います。

- 読む実装: semantic-core/schema/TransformDef.kt の TransformDef

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `id` | 必須 | 文字列 |  | 規則の名前。$apply から指します。 |
| `when` |  | 条件の配列 | いつでも合います | この規則を使う条件（where と同じ書き方）。 |
| `with` |  | 名前の配列 |  | 当てる側が $with で渡す値の名前。規則の中では $of: 名前 で読みます。 |
| `build` | 必須 | ひな型 |  | 組み立てる中身。 |

## 変換定義

YAML から YAML への変換 1 つ。入力を選び（from）、ひな型で組み立てます（build）。出力は YAML の項で、ワークスペースの文書としては保存しません。ここに無いキーは誤りになります。

- 読む実装: semantic-core/schema/TransformDef.kt の TransformDef

| 語 | 必須 | 値の形 | 省いたとき | 意味 |
|---|---|---|---|---|
| `id` | 必須 | 文字列 |  | 変換の ID。 |
| `name` |  | 文字列 |  | 表示名。 |
| `description` |  | 文章 |  | 説明。 |
| `params` |  | 名前の配列（英字で始まる英数字） |  | 受け取る値の名前。ひな型の中では $名前 で読みます。key・index・position は使えません。 |
| `from` |  | {match, also, where, limit} | 呼び出し側が渡した項 1 つが入力です | 入力を選ぶクエリ。書くなら match が必要です。limit を書かなければ、すべての解を相手にします。 |
| `build` | 必須 | ひな型 |  | 出力の中身。 |
| `rules` |  | {id, when, with, build} の配列 |  | 名前を付けた組み立て。 |
