# 図のノード位置

フローとグラフレンズでノードをドラッグすると、そのノードだけを動かし、周囲のノードは同じ位置に留まります。
現在の配置と手動固定の有無をワークスペースに保存します。初回の自動配置も保存対象です。
固定したノードには右上に小さな丸が付きます。背景のドラッグは画面の移動です。

## 移動と解除

- ドラッグ中に Esc を押すと取り消します。
- フローはノードを選択して「選択ノードの固定を解除」、レンズはノードの右クリックから固定を解除できます。
- 固定解除だけでは位置を変えません。「再配置」で、手動固定を保ったまま未固定ノードを並べ直します。
- 「配置を初期化」で、現在の図・選択条件の位置と固定を全て解除し、自動配置し直します。
- 「全体」は負の座標も含めて図を画面に収めます。PNG にも現在の位置が反映されます。

新しいノードが加わると、既存の位置を保ちながら新しいノードだけを空き領域へ配置します。
重なりや辺の混雑が気になるときは「再配置」で並べ直せます。手動固定がある場合は固定位置を優先する共通配置を使います。
レンズの親を動かすと、中のノードも一緒に動きます。子の固定は親を基準に保ちます。
フローの工程は所属するレーン内で移動します。ドラッグで担当レーンは変わりません。
移動に合わせて接続線とラベルも追従します。戻り線は相手に近い面からつなぎ、間にノードがある場合はその外側を通します。
移動したノードが別の線を遮った場合は、その線も引き直します。

配置の保存は原本の編集・「すべて保存」・文書の Undo とは独立しています。
ドラッグの保存に失敗すると元の配置へ戻って理由を表示します。自動配置・再配置の保存失敗時は未保存の配置と理由を表示します。
外部で変更された場合は「配置を再読込」で取り込んでから操作してください。

## 保存の単位

| 図 | 別々に保存する条件 |
|---|---|
| フロー | ビュー・対象文書・レイアウト・方向 |
| レンズ | 実体／型・一体／側面・配置方式・起点・深さ・型と関係の絞り込み・見え方の選択 |

同じ条件に戻すと未固定ノードも含めて現在位置を復元します。画面を離れた後やアプリ再起動後も使えます。
レンズの開閉はこの条件に含めず、閉じた子の位置も残します。パン・ズームは保存しません。
ノードの ID、対象文書の場所、出現の原本パスが変わると、そのノードの位置は再利用されない場合があります。
フローの key が無い・重複している場合は案内を出し、その表示中だけ位置を保持します。

## ワークスペースで共有する

`.yde` 構成では `.yde/state/diagrams/`、従来の構成では `_state/diagrams/` に保存します。
ワークスペースの配布や Git での共有にこのフォルダーを含めてください。ビューの定義には書き込みません。
ファイル名は図と選択条件から作るハッシュで、本文にも対象を記録します。

```yaml
diagram:
  document: processes/example.yaml
  kind: flow
  view: process-flow
selection:
  direction: [down]
  mode: [grouped]
unit: dip
positions:
  - node: {kind: flow, key: ACT-001}
    frame: {kind: lane, key: general}
    at: {x: 48.0, y: 24.0}
    pinned: true
  - node: {kind: flow, key: ACT-002}
    frame: {kind: lane, key: general}
    at: {x: 48.0, y: 160.0}
    pinned: false
  - node: {kind: lane, key: general}
    frame: {root: true}
    at: {x: 24.0, y: 24.0}
    pinned: false
```

座標は表示密度に依存しない単位で、親やレーンがある場合はその内容領域を基準にします。
最外層のノードは `frame: {root: true}` です。`pinned: true` が手動固定、`false` が再配置で動かせる現在位置です。
レーンの原点も保存します。辺・寸法は保存しません。
形式の版番号はありません。読めない形式は通知して自動配置へ戻し、読み込んだだけではファイルを変更しません。
