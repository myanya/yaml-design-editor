# ファイルの場所と画像

`type: file` の項目（[schema.md「型一覧」](schema.md)）には、ワークスペースの中や外にあるファイルの場所を書けます。画像なら、フォームでそのまま見られます。

## 書き方（3 通り）

先頭の文字で見分けます。AI が書くときも同じ規則です。

| 書き方 | 意味 | 例 |
|---|---|---|
| 接頭辞なし | ワークスペースのルートからの相対パス（索引・ビュー・skill と同じ書き方） | `docs/images/flow.png` |
| `./` か `../` で始まる | その文書のあるフォルダからの相対パス（Markdown のリンクと同じ規則） | `./images/flow.png` |
| ドライブ文字・`/`・`file:` で始まる | 絶対パス | `C:/work/diagrams/flow.png` |

区切りは `/` です（`\` は読むときに `/` へ直します）。空のフォルダ名で終わる（`docs/`）・`.` や `..` だけ、といった場所として読めない書き方は違反になります。

## 許す拡張子（`extensions`）

```yaml
- key: diagram
  type: file
  extensions: [png, svg]      # ドットなし。省略すれば制限しない
  description: 業務フローの図
```

`extensions` に無い拡張子は違反です。型（[schema.md「型の定義」](schema.md)）に書けば使う項目へ引き継がれ、使う側が書けば狭めます。AI 生成の制約と「選ぶ」ダイアログの絞り込みにも使われます。

## ワークスペースの外と無いファイル（`files:`）

次の 2 つは、ワークスペースの構成ファイル `.yde/workspace.yaml`（[README.md「ワークスペースの構成」](README.md)）の `files:` で扱いを選べます。

- **ワークスペースの外**: 絶対パスと、`..` でルートの外へ出る相対パス。既定は「許して警告」（`warning`）。
- **無いファイル**: 場所としては読めるが、その場所にファイルが存在しない。既定は「違反」（`error`）。

```yaml
files:
  outside: warning          # allow（許可）/ warning（許して警告）/ error（違反）
  allowedRoots:             # 外でも許す場所（絶対パスの接頭辞。大文字小文字は区別しない）
    - C:/shared/diagrams
  missing: error            # allow / warning / error
```

`allowedRoots` に入る場所は外として扱いません。外を `error` にすると、そのファイルの存在は見ません。

## 検査

| 検査 | 結果 | 扱いを変える場所 |
|---|---|---|
| 場所として読めない | 違反 | — |
| 拡張子が `extensions` に無い | 違反 | スキーマの `extensions` |
| ワークスペースの外 | 既定は警告 | `files.outside`（`allowedRoots` に入る場所は外ではない） |
| 無いファイル | 既定は違反 | `files.missing` |

指摘は項目の場所に付き、フォームの入力枠の色・検証パネル・CLI `validate`（[cli.md](cli.md)）に同じ内容で出ます。

## フォームでの操作

- 入力欄にはそのまま文字で書けます。右の「選ぶ」で OS 標準のダイアログから選ぶと、ワークスペースの中のファイルならルートからの相対パス、外なら絶対パスで書き込みます。
- 「OS で開く」は、OS に関連付けられたアプリでそのファイルを開きます。
- 欄の下に、書き方の種類（ワークスペースのルートから・この文書の場所から・絶対パス）と解決した場所、ファイルの有無が 1 行で出ます。
- 配列の表では、欄と「選ぶ」「OS で開く」だけが列に入り、画像の表示は行を開いたときに出ます。

## 画像の表示

PNG・JPEG・GIF・BMP・WebP・SVG を指す項目は、欄の下に画像をそのまま表示します。

- 既定は欄の幅に合わせた縮小です（幅より小さい画像は拡大しません）。
- 「幅に合わせる」「100%」「−」「＋」と Ctrl＋ホイールで拡大率を変え、ドラッグで表示位置を動かします（業務フローのビューと同じ操作。[flow-views.md](flow-views.md)）。
- 「拡大表示」で編集スペースの全面に出します。ツールバーの「戻る」で元の文書に戻ります。「OS で開く」もここから使えます。
- 画像ファイルが書き換わると、表示は自動で読み直します。
- 拡大率と位置は画面の中の状態で、YAML には書きません。
