# 業務 Web

同じ PC のブラウザから、デスクトップで開いているワークスペースに接続できます。
現在はログイン・ログアウトと、閲覧権限のある保存済み文書の件数に対応しています。
ダッシュボードと業務操作は今後追加します。通常の文書編集・設計はデスクトップで行います。

## 接続する

1. デスクトップでワークスペースを開き、「設定 → 接続と常駐」の Web を ON にします。
2. 「接続者を追加」で機能を Web にし、名前と閲覧権限を登録します。簡単設定の初期値（全体の閲覧だけを許可）でも接続できます。
3. 登録行の「接続コードを発行」を押し、ダイアログの「接続コードをコピー」を押します。
4. 「Web を開く」でブラウザを開き、コードを貼り付けて「接続する」を押します。

API・MCP は OFF のまま使えます。接続先は `http://127.0.0.1:18765/app/`（ポートを変更した場合は設定した番号）です。
ブラウザが開かない場合は「接続先をコピー」を使ってください。接続コードを URL に追記しないでください。

コードの期限は発行から 2 分、使用は 1 回です。閉じるとコードを再表示できません。
使用済み・期限切れならデスクトップから再発行します。再発行すると、同じ接続者の以前の接続も失効します。

## 接続中と終了

概要には、その接続者に閲覧を許可した保存済み文書の件数を表示します。デスクトップの未保存編集は含みません。
「概要を更新」で取り直せます。接続状態と概要は 5 秒ごとにも確認します。
ブラウザの再読込では接続を継続し、同じブラウザのタブは同じ接続を共有します。

接続の期限はコード発行から 30 分です。延長するにはデスクトップから再発行して接続し直します。
「ログアウト」は Cookie とサーバ側の資格情報を失効させます。ブラウザのタブを閉じるだけでは、サーバ側は期限まで接続を保持します。
Web OFF、アプリ終了、ワークスペース切替、接続者の削除・権限変更・失効でも接続できなくなります。
Web OFF は画面と画面用通信の両方を止め、すべての接続機能が OFF になれば待受ポートも閉じます。

接続情報は専用 Cookie で保持し、JavaScript から読めないようにします。
接続コードやトークンは設定ファイル、URL、ブラウザの永続ストレージへ保存しません。
接続できない場合は、デスクトップの Web 欄が「指定: ON / 稼働中」になっていることと、開いているワークスペースを確認してください。

登録権限と常駐については [接続と常駐](local-connections.md) を参照してください。
