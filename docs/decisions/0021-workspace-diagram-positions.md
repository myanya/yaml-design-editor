# ADR-0021: 図の手動位置をワークスペースの表示状態に分離する

- 日付: 2026-11-03
- 状態: 承認済み

## 文脈

flow と lens のノードを利用者が配置し、ワークスペースと一緒に配布したい。
`_views` は定義を書く場所であり、操作に伴って変わる位置情報は混ぜない。
利用者領域の設定だけではワークスペースの共有に含められない。

## 決定

- 位置はワークスペース内の専用状態領域に、図と選択条件の組み合わせごとに保存する。
- 手動の固定位置を自動配置の入力とし、未固定ノードだけを配置する。固定中は共通の固定優先配置を使用する。
- 記録するのは識別子・座標系・手動座標のみ。原本・ビュー定義・射影結果・自動配置結果は書き換えない。
- 状態領域は台帳・文書集合から除外する。位置の保存は文書の Undo・索引・検証・自動実行を起動しない。
- 既存のワークスペース所有権と IO 排他を利用し、外部変更を検出して保存を止める。
- 現段階では版番号・過去形式の読込・移行を持たない。現行形式で読めなければ通知して自動配置へ戻す。

## 既存の決定との関係

ADR-0005 の単一の文書履歴と、ビューは射影で専用の原本書込経路を持たない規律を維持する。
ワークスペースに保存する表示状態は文書編集の対象外と明示する。文書履歴を迂回する業務データの保存には拡張しない。
ADR-0020 の「記法は定義、計測・配置・描画は意味評価の外」という分担を引き継ぐ。

## 影響

保存先と除外判定は `WorkspaceLayout`、表示状態の保存と配置は desktop が担う。
パン・ズーム・開閉を今回の記録に含めず、ビュー語彙も増やさない。
ノードの ID や対象文書の場所を変えた場合、古い配置の自動移行は行わない。
