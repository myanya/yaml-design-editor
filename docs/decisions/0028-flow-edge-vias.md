# ADR-0028: フロー図の線の経由点（ラベルの位置）を表示状態に記録する

- 日付: 2026-11-08
- 状態: 承認済み

## 文脈

flow の線は自動の直角配線で引くため、箱の並びによっては線が大きく回り込み、利用者は曲がる場所を直せない。
ADR-0022 は「寸法・辺の経路・ラベルは派生表示とし、保存しない」と決めており、箱を動かす以外に線を整える手段が無い。
ダッシュボードの業務の流れも flow と同じ部品（`FlowCanvas`）と記録で描くため、線を整える手段は flow の部品に置く。

## 決定

- flow の線のラベルをドラッグすると、その位置（ラベルの中心）をその線の経由点として記録する。線は「元の箱 → 経由点 → 先の箱」を既存の直角配線（`OrthogonalRouting.route`）で 2 回引いてつなぎ、ラベルは経由点を中心に置く。新しい配線の方式は作らない。
- 記録は箱と同じ表示状態の記録（同じ図・同じ選択条件）に入れ、線の一意な `key` で識別する（種類 `flow-edge`・図の原点基準・常に固定）。`key` の欠落・重複した線と、ポートを指定した線（ADR-0024）は経由点を持たない（ラベルを動かせない）。
- 経由点は箱の移動・「再配置」で保つ。「選択した線を自動に戻す」で 1 本ずつ、「配置を初期化」で全て外す。グリッドの吸着はラベルの左上に効かせる。
- 読むだけの図（`FlowCanvas` の `editable = false`）も、同じ記録の経由点で同じ形に描く。PNG の書き出しも同じ。
- 経路そのもの・寸法・経由点を持たない線のラベルは、引き続き派生表示で保存しない。
- lens は対象にしない（需要が立ったら別に決める）。

## 既存の決定との関係

ADR-0022 の「寸法・辺の経路・ラベルは引き続き派生表示とし、保存しない」のうち、flow の線のラベルの位置（経由点）を保存しない部分を上書きする。それ以外（経路と寸法を保存しないこと、現在位置の保持と再配置の扱い）は維持する。
ADR-0021 の表示状態の境界（原本・ビュー定義・索引・文書履歴から分離する）と、ADR-0024 のポートの意味（定義が決める接続口を手で上書きしない）を維持する。

## 影響

記録の形式は変えず、位置の一覧に `flow-edge` の項目が増える。既存の読み手は種類を問わず読むため互換で、経由点を知らない版で開くとその項目は使われない（消されもしない）。
配線は経由点のある線だけ 2 回に分けて引くため、経由点が箱に近すぎるなどで経路が確保できない場合は、既存と同じく経路を確保できない旨を知らせる。
