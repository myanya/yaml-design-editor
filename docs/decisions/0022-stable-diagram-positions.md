# ADR-0022: 図の現在位置を保持し、再配置を明示操作にする

- 日付: 2026-11-03
- 状態: 承認済み

## 文脈

一つのノードを動かすたびに他の未固定ノードも自動配置されると、利用者が調整している図を追いにくい。
手動固定だけの保存では、未固定ノードの現在位置を再起動後に再現できない。

## 決定

- 初回は自動配置し、その結果も現在位置として記録する。
- ドラッグでは対象と接続線を更新し、他のノードの位置を計算し直さない。親の移動では子も追従する。
- ノード集合が変わった場合は一致する既存位置を保持し、記録の無いノードだけを配置する。
- 「再配置」は手動固定を制約として渡し、未固定ノードを並べ直す。
- 個別の固定解除は位置を変えず、次の再配置の対象へ戻す。「配置を初期化」は全ての位置と固定を捨てて自動配置し直す。
- 全ノードの現在位置・座標系・手動固定の有無を保存する。flow のレーン原点も保存し、子の相対位置を再現する。

## 既存の決定との関係

ADR-0021 の「手動座標のみを記録する」と、固定変更に伴って未固定を自動配置する部分を上書きする。
ワークスペースの表示状態として `_views`・原本・索引・文書履歴から分離する境界は維持する。
版番号・過去形式の読込・移行を持たず、現行形式を読めない場合は警告と自動配置へ戻す方針も維持する。

## 影響

現在位置を保存するため、初回の図の表示でも状態ファイルを作成する。
読めない記録や外部競合は自動では上書きしない。利用者の移動・再配置・初期化で明示的に保存する。
寸法・辺の経路・ラベルは引き続き派生表示とし、保存しない。
Core Calculus の対象選択・射影は既存の計算を使い、追加するのは意味評価の外側にある幾何と表示状態である。
