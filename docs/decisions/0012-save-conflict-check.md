# ADR-0012: 保存直前に既知のディスク内容と比較する

- 日付: 2026-10-24
- 状態: 承認済み
- 上書き対象: ADR-0007 の「保存は最終書込み優先」の規定

## 文脈

監視の通知前や、未表示文書を Undo した後の保存でも外部編集を保護する必要がある。
監視による競合バナーだけでは、書き込み時の安全性を保証できない。

## 決定

- `WorkspaceSession.save` と `saveAsText` は書き込み直前に、生テキストと既知のディスク内容を比較する。
- 不一致なら対象文書の書き込み・削除を停止し、未保存内容・保存基準・履歴を残す。新規作成先の衝突と外部削除も不一致に含める。
- 上書き許可は、利用者が許可した時点のディスク内容を次回比較の基準にする。その後の外部変更は再び拒否する。
- 複数文書の保存は成功と失敗を分けて返す。`force` は保存対象の強制指定であり、競合検査を免除しない。
- ファイル配置変更では、検査済みの控えに計画した移動を適用した内容を比較基準とする。
- 単一の Long 連番、意味内容に基づく dirty 判定、履歴の単一所有は変更しない。

## 帰結

生テキストの比較により、更新時刻が同じ変更やコメントだけの変更も検出する。
比較から書き込みまでの OS レベルの排他や、複数文書をまとめた原子性は保証しない。
読み取り失敗は保存失敗として扱い、ファイルが存在しないものとして上書きしない。

Core Calculus 上は、確定済み Rewrite をストアへ反映する I/O 境界の事前条件に属する。
文書内の意味的 Predicate ではなく、workspace-core の既存保存経路の検査であり、YAML の語彙や評価器は追加しない。
