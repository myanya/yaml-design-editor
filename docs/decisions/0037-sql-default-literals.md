# ADR-0037: SQL の初期値の出力方法は型対応表で決める

- 日付: 2026-11-16
- 状態: 承認済み（オーナーの初期値の出力方法を持たせる修正指示。テーブル設計書全体のレビューは継続中）

## 文脈

ADR-0036 は、数値と真偽値も文字列定数として DDL に書き、データベースの型変換に任せていた。
設計からコードを生成するため、どの型をどの表記で出すかは人が書く対応表で指定する。

## 決定

- 型対応表の各行に必須の `literal` を持つ。`string` は引用符付き、`number` は引用符なしの数値、`boolean` は `TRUE` / `FALSE`、`date` は `DATE 'YYYY-MM-DD'`。
- 基本設計の初期値は YDE の値のまま保持する。テーブル設計書は、初期値の設定の有無・値・出力方法を別々に見せる。空文字・0・false・文字列の「設定なし」も設定された値である。
- レポートの変換定義が出力方法を選び、数値の表記と真偽値の大文字化には既存の値の式を使う。値の見た目や SQL の型名から推測しない。
- 文字列の引用符の処理だけを、既存の文字のひな形の出力形式 `sql-string` に加える。`'` を `''` にして囲む決定的な出力形式であり、SQL の評価や型の選択を行わない。空文字も `''` にする。
- 保存時の自動値（`auto: created` など）はこの初期値と別で、従来どおり Service の責務。SQL の式や Java の型・初期化方法は今回の対象に含めない。

## 既存の決定との関係

ADR-0036 の「初期値は文字の値として書く（データベースが列の型に直す）」だけを本 ADR で上書きする。
