# ADR-0023: グリッド編集補助を図の表示状態として保存する

- 日付: 2026-11-03
- 状態: 承認済み

## 文脈

flow・lens の手動配置にグリッド吸着を加え、ワークスペースと一緒に設定を共有したい。
切替によって調整中の配置が動いたり、別の配置へ切り替わったりすることは避けたい。

## 決定

- 吸着の有無と間隔は、既存の図・選択条件ごとの配置ファイルへ任意の `grid` 項目として保存する。
- グリッド設定を図・選択条件の識別に含めない。省略時は OFF・16 dip とし、版番号や移行処理を設けない。
- 設定変更ではノードを動かさず、手動ドラッグだけに吸着を適用する。自動配置と明示的な再配置は既存の配置計算を使う。
- 保存座標と同じ原点・単位を使い、親の移動では子の相対位置を保つ。設定は位置の初期化で消さない。

## 既存の決定との関係

ADR-0021・ADR-0022 の保存対象に、グリッドの編集補助設定を追加する。
定義・原本・文書履歴から分離する境界と、位置を保持して再配置を明示操作にする方針は維持する。

## 影響

位置と設定は同じ競合検出・保存処理を使う。旧アプリは未対応項目を含む記録を読めない場合がある。
Core Calculus の対象選択・射影は既存の計算を使い、追加するのは意味評価の外にある幾何と表示状態だけである。
操作と描画の規律は [図の手動位置](../architecture/diagram-positions.md) に置く。
