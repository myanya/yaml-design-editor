# 意図的差分一覧

3層コア移行で**最初から意図して変える**既存挙動の台帳（計画書§2.3）。
新旧比較テストでこの表に該当する差分が出た場合、移植ミスとして扱わず、新旧それぞれの期待値を明記する。
ここに載っていない差分はすべて移植ミスの疑いとして調査する。
