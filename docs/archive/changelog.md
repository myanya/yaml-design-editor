# チェンジログ

YAML Design Editor の利用者向け変更履歴。0.1.0 を初期リリースとし、それ以前の機能は初期リリースの内容にまとめる。
各版の内容はローカルの Git タグ `v0.1.0`〜`v0.1.5` に基づく。日付はタグが指すコミットの日本時間の日付で、配布物の公開日を示すものではない。
0.1.1 以降は直前のタグとの差分から、利用者に関係する追加・変更・修正を記載する。

## 0.1.5 — 2026-10-24

### 改善

- Undo/Redo 後に、変更を行ったフォーム・ビュー・ソースの画面へ戻るようにした。対象と保存状態も通知する。
- 保存と画面移動を連続入力の区切りとし、戻ってからの編集を別の Undo で取り消せるようにした。
- 一括変更と、それに伴う更新日・版などの自動値を、1 回の Undo でまとめて戻せるようにした。
- 通常の再読込で、未保存の編集・ソースの下書き・Undo/Redo・ファイル配置の履歴を保持するようにした。
- 編集と履歴を明示的に破棄する再読込を追加した。対象を確認し、新しい内容の読込に成功してから破棄する。
- 外部変更と競合する保存や Undo/Redo を停止し、明示的な上書き許可またはディスク版の採用で解決できるようにした。
- 外部版を採用した文書に対する古い Undo/Redo は適用を拒否する。スキーマや構成の再読込に失敗した場合も、現在の編集と履歴を保持する。

### 修正

- 入力・解析待ちのソースを反映してから Undo/Redo を行い、古い解析結果や確認中の履歴変更が混入しないようにした。
- 文書を直接編集するフォーム入力の Undo/Redo をワークスペース履歴に統一し、IME 変換中のキー操作が文書の Undo に伝わることを防いだ。
- 画面に表示していない文書にも履歴操作後の値と未保存状態を反映し、「すべて保存」の対象に含めるようにした。
- Undo/Redo に伴うソース同期で、表記と未保存の変更を保護するようにした。
- 改名や Undo 後の文書の画面への反映タイミングを修正し、描画時のクラッシュを防いだ。

## 0.1.4 — 2026-10-24

### 追加

- ファイル一覧で YAML 以外の形式も表示できるようにし、隠し項目・除外・名前／パス検索と、フォルダー展開状態の永続化に対応した。
- 一般テキストの閲覧、複数選択、キーボード操作、ドラッグによるファイル移動に対応した。
- 参考資料の本文検索を追加した。検索範囲・読込量・件数・時間を制限でき、中止や上限到達時には一部の結果であることを表示する。
- Kotlin・Java・Python・JavaScript／TypeScript の宣言候補を構造として閲覧し、原文の位置へ移動したり、別の YAML 文書へ保存したりできるようにした。

### 改善・修正

- ファイル一覧を ID 索引から分離し、表示対象を増やしても台帳の索引対象が増えないようにした。必要な枝だけを読み、隠し領域の不要な走査を減らした。
- ファイル・フォルダーの移動や改名で、文書参照・型付きファイルパス・Markdown リンク・パスに依存する定義の変更をまとめて確認・適用できるようにした。
- 移動・改名・削除と関連定義の修正を同じ履歴で Undo/Redo できるようにした。削除対象は退避し、外部変更との競合検出と失敗時の復元に対応した。
- ドラッグ案内を固定行にまとめ、操作中にツリーが上下へ動く問題を修正した。移動先も強調表示する。

## 0.1.3 — 2026-10-23

### 改善

- フォームの表示方式をアイコン操作に統一し、表示の固定／可変とファイルごとの指定に対応した。指定がないファイルは直前の表示方式を引き継ぐ。
- フォームの入力欄で Esc を押したとき、入力内容を保持してフォーカスを外すようにした。
- 選択一覧の現在値をチェックと背景色で示し、高さの制限・現在値へのスクロール・全文表示・検索を整備した。
- ソースの構文状態を固定高の領域に表示し、エラー詳細の開閉で編集位置が動かないようにした。詳細の全文表示・コピー・該当行への移動に対応した。

### 修正

- フォームのスクロールや折り畳みに、構成ツリーの選択が追従するようにした。
- 項目説明のホバー表示を小さくし、空白部分で反応しないようにした。

## 0.1.2 — 2026-10-20

### 改善

- 通常フォームとスキーマ設計を、構成ツリーと詳細編集を組み合わせた画面に統一した。
- 通常文書の初期表示を構成ツリーと選択項目のフォームに変更し、全体連動・全体のみを含む表示方式を共通化した。表示方式・選択・開閉を文書ごとに保持する。
- スキーマ編集の上部操作を集約して編集領域を広げ、狭い画面では構成と詳細を切り替えて使えるようにした。
- フォームを表示幅に合わせ、複合値の縦配置、余白と字下げの調整、項目説明の全文表示に対応した。文書情報と他文書の定義は既定で折り畳む。
- ライト／ダークの配色、標準メニュー、左右ペインの操作を整理し、ウィンドウタイトルにワークスペースのフルパスを表示するようにした。

### 修正

- 配列要素を追加したときの描画例外を防いだ。
- テーブル展開時にフォームが横へはみ出す問題を修正した。
- スキーマ文書を切り替えたとき、前の文書の入力値が残る問題を修正した。

## 0.1.1 — 2026-10-17

### 追加

- グラフレンズに「実体／型」の切替を追加した。型・関係・保有の構造からスキーマを閲覧でき、CLI `schema-graph` でも出力できる。
- レンズのビュー定義で、関係ごとの矢印の表示方向と逆向きのラベルを指定できるようにした。
- ソース編集に検索一致の強調・一致間の移動・正規表現・行へ移動・自動インデント・行の移動／複製・コメント切替を追加した。
- ソース上の検証指摘、Ctrl+Space によるキー・ID・選択肢・ファイルの補完、ホバーによる項目説明、Ctrl+クリックによる参照先への移動を追加した。
- ソースの折り畳み、保存済み内容との差分の印、フォームとの編集位置の同期、選択範囲の整形を追加した。

### 改善・変更

- ソースの下書き・カーソル・解析エラーを文書ごとに保持し、タブや文書を移動しても残るようにした。
- 入力が止まってからソースを解析し、成功時にフォームへ反映するようにした。他の画面で行った変更は、ソースの変更箇所へ差し込む。
- 構文エラーのあるソースもテキストとして保存できるようにした。解析できない間はフォームを閲覧専用にし、下書きを破棄する Undo/Redo には確認を出す。
- 編集画面のタブを文書ごとに記憶し、未指定の文書は直前のタブを引き継ぐようにした。ソースの行番号の整列、折り返しと横スクロールも整備した。

## 0.1.0 — 2026-10-15

初期リリース。以下の機能を提供する。

- スキーマに沿った YAML のフォーム／ソース／差分編集と、スキーマのない文書の汎用ツリー編集。
- コメント・表記を保持する YAML 入出力、複数ドキュメント YAML、Undo/Redo と未保存状態の管理。
- スキーマ設計、型の再利用、フェーズ別の必須項目、値の式、更新日・版などの自動値。
- 文書をまたぐ ID 索引と参照解決、補完、バックリンク、エンティティページ、改名・統合などのリファクタリング。
- スキーマ・参照・関係・網羅性など、YAML の定義体に基づく検証と指摘の表示。
- 一覧・マトリクス・文書・フローのビューとグラフレンズ、原本に反映するビュー上の編集と一括編集。
- 型の操作とアクションの定義、差分を確認して適用する画面・CLI・エージェントからの実行。
- OpenAI / Anthropic による作成支援、エージェント実行、変更セットのレビューと承認後の適用。
- ヘッドレス CLI による探索・検索・検証・変換・入出力と、ワークスペースの初期化。
- Java ランタイム、起動案内、TODO サンプル、ライセンス表示を含む Windows x64 ZIP 配布と SHA-256 チェックサム。
