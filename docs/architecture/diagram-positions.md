# 図の手動位置

flow と lens の位置は、意味モデルから分離した表示状態としてワークスペースに記録する。
定義・射影結果・原本を変更しない。[状態の境界](../decisions/0021-workspace-diagram-positions.md) と [位置保持と再配置](../decisions/0022-stable-diagram-positions.md) に決定を記す。

## 部品と流れ

| 部品 | 責務 |
|---|---|
| `desktop/DiagramPositions.kt` | 図と選択条件の識別、現行形式の検査、非同期の読込・保存、競合通知 |
| `ui/common/DiagramGrid.kt` / `DiagramGridControls.kt` | グリッドへの吸着、丸め前の移動量の蓄積、設定操作と点グリッドの描画 |
| `ScreenMemory.diagramPositions` | ワークスペース寿命の読込結果と保存中の状態 |
| `ui/common/PinnedLayout.kt` | 固定矩形を先に置き、未固定矩形だけを空きへ配置 |
| `ui/common/OrthogonalRouting.kt` | 接続面の選択、折れ数を含む経路探索、線分に沿ったラベル配置 |
| `ui/common/PinnedFlow.kt` | レーンの内容座標と図の座標の変換、レーンの組立、辺とラベルの再配置 |
| `GraphLayouts.arrangeNested` | 親の寸法を子から計算し、親基準の固定位置を段ごとに適用 |
| `FlowPositions.kt` / `LensPositions.kt` | 全ノードの現在位置を識別子・親基準へ変換し、手動固定の区別を保持 |
| `FlowViewPane` / `GraphLensView` | 座標の計測・ジェスチャー・一時プレビュー・保存要求・通知 |

1. 意味モデルを解決し、表示するノードとその寸法を求める。
2. 図・選択条件・ノード識別子・親の一致する記録だけを配置入力に渡す。dip は現在の表示密度で px に換算する。
3. 現在位置を先に置き、記録の無いノードだけを配置する。初回は自動配置し、表示した全ノードの位置を記録する。
4. ドラッグ中は対象と接続線のプレビューだけを変える。終了時に全位置と対象の固定フラグを保存し、成功したプレビューをそのまま確定する。
5. Esc・ジェスチャー中断では保存しない。ドラッグの保存失敗時は確定済みの配置に戻し、理由を表示する。自動配置・再配置の保存失敗時は表示結果を残して通知する。
6. 「再配置」だけは手動固定を制約にし、未固定ノードを並べ直す。個別の固定解除では現在位置を保持する。

## 配置の規律

- 通常の配置入力は全ての現在位置、明示的な再配置の入力は手動固定だけ。制約が無い場合は選択した自動配置を使い、ある場合は共通の固定優先配置を使う。
- 配置するノードは接続相手との近さと flow の方向を優先する。既存位置同士の重なりは勝手に解消せず通知する。
- 配置計算では矩形を避けて辺を引き、ラベルはノードと他のラベルを避ける。経路を確保できない辺は通知する。大図の経路探索には格子数と探索回数の上限を設ける。
- ドラッグでは対象に接続する辺と、新たにノードに遮られた辺を引き直す。その他の辺はそのまま保ち、ノードの位置は再計算しない。表示する位置と保存座標が一致した場合はプレビューを確定する。
- flow の移動・固定位置からの配置、lens の直交線の更新は共通の経路計算を使う。移動前の接続面を優先し、相手を通り越した場合は向かい合う面に切り替える。
- 接続面から垂直に出入りする短い折れ線を優先する。障害物が多い場合は進入軸を含む格子探索で長さと折れ数を評価し、不要な逆走を避ける。ラベルは線分のそばへ追従させる。
- lens は最外層を図の原点、子を親の見出し直下の左端で記録する。親を動かすと、個別に固定された子も親基準を保って動く。移動後の直交線は親の枠を障害物から外して引き直し、親子を直接結ぶ線は直線で保つ。
- flow は最外層を図の原点、所属するノードをレーンの内容領域の左上で記録する。レーンなし表示は全て最外層。ドラッグは所属を変えず、レーン内のノードを内容領域に留める。
- スイムレーンの新規・未割当ノードは帯の外へ置く。既存の帯の原点とノード位置は保持し、帯が拡大しても押し出さない。並びを整える操作は「再配置」に分ける。
- パン・ズーム・ホバーは保存しない。全体表示・ミニマップ・PNG は負の座標を含む実際の描画範囲を使う。

## 記録の識別と形式

場所は `WorkspaceLayout.diagramStateDir`。レガシー構成は `_state/diagrams`、`.yde` 構成は `.yde/state/diagrams`。
配下は `<図のハッシュ>/<選択条件のハッシュ>.yaml`。正規化したマップの SHA-256 を使い、原本ファイル名や ID を物理パスへ直接埋め込まない。
本文にも図と条件を持ち、読込時に照合する。ワークスペース絶対パスは使わない。

| 種類 | 図の識別 | 選択条件 |
|---|---|---|
| flow | ビュー ID・対象文書の相対 ID | 表示モード・実効方向 |
| lens | 実体／型・一体／出現 | 配置方式・起点・深さ・隠した型と関係・記法の選択 |

条件のキーと集合を整列する。開閉・選択・ウィンドウ寸法・文書の版・現在のノード集合は条件に含めない。
ノードは flow の一意な key、lens の実体 ID／型名、出現は ID・文書 ID・原本パスで識別する。
欠落・重複した flow の key はその表示中だけ保持し、保存しない。親の識別が変わった固定は適用しない。
表示から消えたノードの記録は維持し、同じ識別が戻ったときに再利用する。ID 改名・文書移動への追随は行わない。

本文は `diagram`・`selection`・`unit: dip`・`positions` と任意の `grid`。各位置は `node`・`frame`・`at: {x, y}`・`pinned` を持つ。
`frame: {root: true}` は図の原点、それ以外は親の識別子。全ノードの自動・手動の現在位置と flow のレーン原点を記録し、寸法・経路・ラベルは記録しない。
`pinned: true` は次の再配置でも保持する手動固定。`false` も通常時は位置を保持するが、再配置の対象になる。
`version` / `formatVersion` は設けず、現行形式だけを検査する。読めない形式は警告して自動配置し、読込だけでは書き換えない。

## グリッド吸着

- `grid: {enabled: false, spacing: 16}` を同じ記録に保存する。省略時はこの既定値、間隔は 8・16・32 dip。選択条件のキーには含めない。
- ON/OFF と間隔の変更は現在位置・固定・経路を変えない。自動配置・再配置へはグリッドを渡さず、ドラッグ中のノード左上だけを最寄りの点へ合わせる。
- 原点は保存座標と一致させ、最外層は図の原点、子は親やレーンの内容領域の左上とする。親を動かしても子の相対座標は変えない。
- ポインタの移動はズームを逆変換して丸め前の値へ蓄積する。表示・確定時だけ吸着し、境界では範囲内の格子点を選ぶ。格子点がない範囲では枠内に留める制約を優先する。
- 点グリッドはパン・ズームに追従し、各内容領域の原点で描く。箱・見出しには重ねず、縮小時は描く点を間引く。吸着間隔や保存座標は間引きに影響されない。
- 「配置を初期化」でもグリッド設定は保持する。保存の競合検出・排他は位置と共有し、保存成功後に設定を確定する。PNG に編集補助の点は含めない。

表示状態の保存範囲は [グリッド編集補助の決定](../decisions/0023-diagram-grid-editing.md) に記す。

## 保存とワークスペースの境界

- 読込・保存は `AppState.operationScope` で画面の寿命から分離する。書込は既存の `WorkspaceHost.exclusive` の下で対象ワークスペースを照合し、独立した IO を完了させる。
- `WorkspacePaths` で境界を確認し、読込済み本文との比較と一時ファイルからの atomic move で保存する。保存成功まで共有の位置を確定しない。
- 外部変更との競合は上書きせず通知する。「配置を再読込」で取り込み、再操作する。OS 全体での比較・書込の排他は保証しない。
- 初回配置とノード追加の結果は自動保存する。読込・保存の警告がある場合の自動保存は止め、明示的な移動・再配置・初期化を待つ。
- `FileSystemDocumentStore`・`WorkspaceReader`・`WorkspaceScan` は状態領域を文書集合へ載せない。増分通知でも除外し、索引・検証・自動実行・文書 Undo を動かさない。ファイル一覧から開いた場合は閲覧用プレビューにする。
- `_views` とスキーマは定義だけを保持する。表示状態にメタスキーマや専用の原本編集経路を追加しない。CLI `migrate` は状態領域も移し、内容は変えない。
- Core Calculus の対象選択・射影は既存の計算を利用する。ここで追加するのは幾何と表示状態の保存で、意味の演算・独立した Undo 系は追加しない。
