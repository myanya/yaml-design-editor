# 課題管理

テンプレート「課題管理」から作ったワークスペースです。課題を 1 件 1 ファイルで `issues/` に置き、形は `.yde/schemas/issue.yaml` が決めます。

| 場所 | 内容 |
|---|---|
| `issues/ISSUE-001.yaml` ほか | 課題の原本（1 件 1 ファイル） |
| `.yde/schemas/issue.yaml` | 課題の形（ID・件名・状態・優先度・担当・タグ・内容・棚卸しメモ） |
| `.yde/skills/` | Excel の台帳の取り込みと、Excel・Markdown への書き出し |
| `.yde/agents/` と `.yde/activities/` | 棚卸しのエージェントと、その仕事の定義（AI 接続が要ります） |
| `.yde/evals/` | 棚卸しの回帰評価 |

## 次にできること

- 編集スペースで `issues/` に新しい YAML を作ると、スキーマの初期値が入ったフォームが開きます。
- 設計スペースの「連携（skill）」から、Excel の台帳を取り込んだり、帳票を書き出したりできます。
- 項目を足したいときは、設計スペースの「スキーマ」で `issue.yaml` を開きます。
