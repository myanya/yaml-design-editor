# {label}の台帳

「新しいワークスペースを作る」の「自分の項目で」から作ったワークスペースです。管理するものは「{label}」で、ID は「{prefix}-001」のように付きます。

| 場所 | 内容 |
|---|---|
| `{code}/` | {label}の原本です |
| `.yde/schemas/{code}.yaml` | {label}の形（項目・ID の形式・登録の操作）です |
| `.yde/views/{code}-grid.yaml` | {label}の一覧ビューです |
| `.yde/views/{code}-dashboard.yaml` | 開いたときの入口になるダッシュボードです |

## 次にできること

- ダッシュボードの「{label}を登録する」で 1 件目を足します。ID は、一覧 1 ファイルでは自動で付き、1 件 1 ファイルでは登録のときに未使用の番号を入れます。
- 項目を足したいときは、設計スペースの「スキーマ」で `{code}.yaml` を開きます。
- 一覧の列を変えたいときは `{code}-grid.yaml`、ダッシュボードの区画を変えたいときは `{code}-dashboard.yaml` を開きます。
- 使い方は「ヘルプ → 利用者マニュアル」にあります。
