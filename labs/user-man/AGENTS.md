# AGENTS.md

このディレクトリは、架空のユーザ管理システムを題材に設計書・テストケースのひな形を育てるYDEワークスペースです。
目的・設計体系・配置は [README.md](README.md) を参照してください。
仕様書の構成は [10_specs/README.md](10_specs/README.md)、命名・ID・参照は [共通記述規約](10_specs/WRITING.md) に従ってください。
種類ごとの項目・記述例は各ディレクトリのREADME、操作・検証は [OPERATIONS.md](OPERATIONS.md) に記載し、入口のREADMEへ詳細を集約しないでください。
業務・システム仕様の追加検討事項と進捗は [TODO.md](TODO.md) を参照し、セッション開始時に「再開位置」を確認してください。

## 作業方針

- 利用者が説明する架空のシステムの業務仕様と、本ワークスペースで定める文書構成・記述方針を基準に、まず `10_specs/` の仕様書を作ります。
- 一般的なユーザ管理システムの機能を、確認済みの仕様として補わないでください。
- 不明点や確認事項は基本的にチャットで質問し、文書内に質問欄や確認待ちの質問を追加しないでください。
- ヒアリング事項はなるべくまとめて提示してください。同じ検討項目で関連する質問を1問ずつ小出しにせず、既に回答済みの事項は再質問しないでください。
- 質問前に過去の回答と関連ルールを確認し、既存の方針や文脈で判断できる点は整理して反映してください。回答のない業務判断は確定扱いにせず、残る論点として区別してください。
- 利用者の指定により、検討の状態・未解決の論点・回答済みで未反映の内容・次の一手は `TODO.md` に記録します。セッション終了前や話題の切り替え時にも更新してください。
- 回答で確定した内容を該当する本文へ反映し、不明な内容を推測で確定しないでください。
- 文書の粒度・項目・ID規則は、利用者との作業で決めます。
- 後続工程の文書や、本ツールの機能拡張を先回りして追加しないでください。
- YDE内蔵のエージェント・アクティビティ・自動実行は当面使用しません。
- YAMLとスキーマの編集後は、可能ならOPERATIONS.mdのCLIで検証し、実行できなかった確認は報告してください。
- `.tooldocs/` にマニュアルがある場合は参照し、なければ本リポジトリの `docs/manual/` を参照してください。
