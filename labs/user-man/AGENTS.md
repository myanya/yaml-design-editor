# AGENTS.md

このディレクトリは、ユーザ管理システムを題材に設計書・テストケースのひな形を育てるYDEワークスペースです。
目的・設計体系・配置・操作方法は [README.md](README.md) を参照してください。
仕様書の構成・命名・ID体系・未決事項は [10_specs/README.md](10_specs/README.md) を参照し、更新も同じ文書にまとめてください。
業務・システム仕様の追加検討事項と進捗は [TODO.md](TODO.md) を参照し、セッション開始時に「再開位置」を確認してください。

## 作業方針

- 利用者が説明する業務仕様と会社の設計体系を基準に、まず `10_specs/` の仕様書を作ります。
- 一般的なユーザ管理システムの機能を、確認済みの仕様として補わないでください。
- 不明点や確認事項は基本的にチャットで質問し、文書内に質問欄や確認待ちの質問を追加しないでください。
- 利用者の指定により、検討の状態・未解決の論点・回答済みで未反映の内容・次の一手は `TODO.md` に記録します。セッション終了前や話題の切り替え時にも更新してください。
- 回答で確定した内容を該当する本文へ反映し、不明な内容を推測で確定しないでください。
- 文書の粒度・項目・ID規則は、利用者との作業で決めます。
- 後続工程の文書や、本ツールの機能拡張を先回りして追加しないでください。
- YDE内蔵のエージェント・アクティビティ・自動実行は当面使用しません。
- YAMLとスキーマの編集後は、可能ならREADMEのCLIで検証し、実行できなかった確認は報告してください。
- `.tooldocs/` にマニュアルがある場合は参照し、なければ本リポジトリの `docs/manual/` を参照してください。
