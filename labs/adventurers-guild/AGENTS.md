# AGENTS.md

本ワークスペースは、YDE（YAML Design Editor）で架空の冒険者ギルドの運営のオントロジーを定義する試作です。
目的・配置・オントロジーを書く場所は `README.md`、初案・段階・決まったこと・再開位置は `PLAN.md` を参照してください。
`.tooldocs` にツールの使い方がある場合は、そのマニュアルに沿って YAML ファイルを作成・編集してください。リポジトリ内で `.tooldocs` がない場合は、ルートの `docs/manual/` を参照してください。

## 作業方針

- セッションの始めに `PLAN.md` の「再開位置」と「決まったこと」を読みます。
- ギルドの運営の決まり（ランクの体系・報酬と手数料・受注の条件など）は業務の判断で、オーナーが決めます。一般的な冒険者ギルドの設定を、確認済みの決まりとして補わないでください。決まっていないことは `PLAN.md` に論点として残します。
- 質問はチャットでまとめて出します。回答済みのことは再質問せず、回答は `PLAN.md` の「決まったこと」と本文へ反映します。
- 定義は製品の機能だけで書きます（`labs/` のために製品のコードを足さない）。足りない語彙や気になりポイントは、直しに行かずリポジトリの devtrack へ登録します（ルートの `AGENTS.md`「ワークフロー」）。
- 検査は、関係レジストリの多重度 → パターン制約 → 型の検査 → 遷移検証の順に、既存の語彙で書けるかを確かめます。
- YDE 内蔵のエージェント・アクティビティ・自動実行は、オーナーが決めるまで使いません。
- セッションの終わりや話題の切り替えでは、`PLAN.md` の「いまの姿」と「再開位置」を更新します。

## 決まり

- ID・項目名・関係名・型の名前は英語（関係名と型の名前は小文字とハイフン）、`label` と `description` は日本語で書きます。
- 参照には必ず `relation` を書き、関係レジストリに宣言します。
- 運営データの人物・団体・地名・魔物・品物は架空のオリジナルにし、名前は実在のものや既存の作品と重ならない造語にします。既存の作品の設定（固有の用語・ランクの呼び名の体系・登場人物）を写しません。
- GitHub で公開されるため、出どころの分からない素材（画像・音・フォント）を置きません。
- YAML とスキーマを直したら、リポジトリのルートで `./gradlew runCli -q --args="validate labs/adventurers-guild"` を実行し、結果の件数を `PLAN.md` の「いまの姿」と比べます。わざと入れた指摘は、どれか分かるように `PLAN.md` に書きます。
