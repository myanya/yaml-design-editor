- 却下・取消・期限切れの理由は、いまは依頼の備考 `note` に書く。理由の項目と日付は、段階 3 の操作を作るときに決める。

## 全体方針

1. **YDE の定義そのものをオントロジーにする**。概念はオブジェクト型の `entity`、関係は参照の `relation` と関係レジストリ、公理と運営の決まりは検査、個体は台帳の YAML（[README](README.md)「オントロジーを書く場所」）。
2. **小さく一周させてから広げる**。依頼の受付から精算までの核（段階 1〜3）を先に作り、検査とビューで確かめてから世界（場所・魔物・素材）と運営（職員・規約・会計）を足す。
3. **製品の機能だけで書く**。書けない決まりや見え方は、無理に回避せずリポジトリの devtrack に登録し、製品側で直すかは個別に判断する。
4. **検査は定義体で書き、既存の語彙で書ける順に当てる**。関係レジストリの多重度 → パターン制約 → 型の検査（値の式）→ 遷移検証。決まりごとに、どの書き方に落ちたかをこの計画に残す。
5. **関係は片側に書く**。参照は書く側を 1 つに決め、逆向きは関係レジストリの `inverseLabel` で読む。それ自身に属性や状態がある関係（受注など）は、ID を持つ要素にする（1:N 具体化）。
6. **1 件 1 ファイルと一覧を使い分ける**。冒険者・依頼のように増えて個別に育つものは 1 件 1 ファイル、ランクのような小さな区分は一覧 1 ファイル。
7. **データは架空のオリジナル**。既存の作品の設定を写さない（[AGENTS.md](AGENTS.md)「決まり」）。

### 状態

初案のまま始め、詳細は徐々に詰める（オーナーの決定）。選択肢は `common.yaml` の `依頼の状態`・`冒険者の状態`。

- 依頼: 受付 `received` → 掲示中 `posted` → 受注済み `assigned` → 報告済み `reported` → 精算済み `settled`。途中で 却下 `rejected`・取消 `cancelled`・失敗 `failed`・期限切れ `expired` に分かれる。
- 冒険者: 現役 `active`・休業 `resting`・引退 `retired`・除名 `expelled`・消息不明 `missing`。
- 状態は操作（工程）で変え、操作の前提（`require`）で決まった移り方だけを許す。移り方そのものを台帳にして遷移検証（`flow`）で確かめるかは段階 3 で決める。

### 運営の決まり（検査の候補）

| 決まり（案） | 書き方の見込み | 段階 |
| --- | --- | --- |
| 依頼には依頼者が 1 人いる | 関係レジストリの多重度（済） | 1 |
| パーティにはリーダーが 1 人いる | 関係レジストリの多重度（済） | 1 |
| パーティのリーダーは構成員の 1 人である | パターン制約（`same` で合流を確かめる） | 2 |
| パーティの人数は上限まで | 関係レジストリの多重度 | 2 |
| 受けた者のランクは依頼の下限以上 | パターン制約の `check`（ランクの `order` を比べる） | 2 |
| 引退・除名・消息不明の冒険者は受注できない | パターン制約の `absent` | 2 |
| 同時に受けられる依頼の数はランクごとの上限まで | パターン制約の `check`（`count` と `all` で数え、ランクの上限と比べる） | 2 |
| 受注済み以降の依頼には受注がある | 型の検査（`where` で状態を絞る） | 2 |
| 報告済み・精算済み・失敗の依頼には完了報告がある | 型の検査かパターン制約（`where` で状態を絞る） | 2 |
| 受注日・報告日は受付日以降で、報告日は期限以内（過ぎれば警告） | 型の検査（日付の `gte`・`lte`） | 2 |
| 精算額は報酬額から手数料を引いた額 | 型の検査（値の式） | 2 |
| 受注は 1 回だけ精算される | 関係レジストリの多重度（入 0〜1） | 2 |

### 見え方と操作の候補

- 一覧: 依頼の掲示板・冒険者の名簿・パーティの編成（grid）。
- 集計: ランク × 依頼の種別のクロス集計、月ごとの報酬と手数料（chart）。
- 操作: 依頼を受け付ける・掲示する・受注する・報告する・精算する（`actions`）。冒険者を登録する・パーティを組む（`create` と `insert`）。
- ダッシュボード: 受付の状況。状態ごとの区画を段、操作を工程にした業務の流れ。
- 図: レンズの型の段でオントロジーの全体、実体の段で依頼と冒険者のつながり。
