# 家計簿整備計画

目的: 試作を「毎月の家計簿として回せる」ところまで整え、`samples/` へ置き直せる形にする。この文書は案で、順番と着手はオーナーが決める。大きさの目安は、小＝半日以内・中＝1 日。

## いまの姿（2026-09-28）

- できていること: 費目・月・取引・予算の 4 エンティティ、検査 4 つ、ビュー 6 つ（月×費目の手書き・クロス集計・列を広げる書き方、月×区分、月×費目の件数、取引明細）、三井住友銀行の CSV の取り込み（採番・同じ明細の見分け）、桁区切り、日付順。
- 検査の基準: エラー 2・警告 3（わざと入れた食い違い 3 件と、取り込んだ取引の未分類 2 件）。
- 決めていること（変えない）は [README.md](README.md) と [HANDOVER.md](HANDOVER.md) にある。

## 決まったこと・済んだこと

- 1-1 済（2026-09-28）: 費目の規則は skill に直書き（`$first` と `$when` の `contains`）。架空の 2 つ目の CSV（`inbox/smbc-sample-2.csv`）で当たり方を見られる。
- 1-2 済（2026-09-28）: 月の文書はファイル名を ID にし、月次サマリの「新規行」（ファイルモード）で作る。年月・前月・期首残高は表の上で埋める。
- 2-1 済（2026-09-28）: 手書きの月×費目は「月次サマリ」（期首・収入・支出・期末）に改名し、件数のビューは削除。クロス集計と列を広げる書き方は、比較として両方残す（オーナーの決定）。
- 1-3 済（2026-09-28）: 実績・予算・差額の 3 つを並べる（オーナーの決定）。行は予算（月×費目）で、`budget-vs-actual.yaml`。
- 1-4 決定: 年またぎは運用で逃がす（12 月までと 1 月からで分けてダウンロードする）。汎用ツールに特定用途の仕掛けは足さない。
- 3-1 済（2026-09-28）: 取り込んだ 2021 年の結果は `book/` から外し、`inbox/` の CSV を「月を作ってから取り込むと 2 件増える」筋書きにした。検査の基準はエラー 2・警告 1。
- 3-2 済（2026-09-28）: `KakeiboLabTest`（一時ディレクトリへ写して検査の件数・ビューと skill の読み込み・取り込みのプレビュー・クロス集計と列を広げる書き方の一致を確かめる）。
- 3-3 済（2026-09-28）: README に「使い始める（毎月の流れ）」、AGENTS.md を追加。HANDOVER と PLAN は labs 向けのまま。

## 段階 1: 月次の運用を一周させる

| 番号 | やること | 中身 | 判断が要ること | 大きさ |
| --- | --- | --- | --- | --- |
| 1-1 | 取り込んだ取引の費目付け | skill の `build` に、摘要の言葉で費目を当てる規則を書く（`$first` の中に `$when: { path: 摘要, contains: スーパー }, $then: CAT-FOOD` を並べ、当たらなければ `CAT-UNSORTED`）。いまの語彙で書ける | 規則を skill に直書きするか、費目の文書に「摘要の言葉」の項目を持たせるか。部分一致は skill 側にしか無いので、まず直書きを提案 | 小 |
| 1-2 | 月初の手順を 1 操作にする | 新しい月の文書を、取引明細か月のビューの「新規行」（ファイルモード）と `scaffold` で作る。前月への参照と期首残高の枠が入った形で作られ、期首残高は手で写す（決定どおり）。不便なら「前月の期末を写す」組込みエージェント（決定の条件） | 入口をビューの新規行にするか、CLI にするか | 小〜中 |
| 1-3 | 予算と実績の対比 | 予算は月×費目で書いてあるので、月ごとに費目の「実績・予算・差額」を並べるビュー。列を広げる書き方（`each`）で費目ごとの差額を 1 列にする案と、クロス集計を 2 つ（実績・予算）並べる案 | 差額だけを見せるか、3 つを並べるか | 小 |
| 1-4 | 実物の CSV で試す | 実物は Shift_JIS・年またぎ・他行の形が違う。オーナーの実物（個人情報を伏せたもの）があれば skill を合わせる。年またぎは「月 < 対象日（自）_月 なら至の年」の条件が要るが、ひな型の条件の比較相手は決まった値だけなので、いまの語彙では書けない | 年またぎは「12 月と 1 月を分けて出力する運用」で逃げるか、変換に値どうしの比較を足す（製品側）か | 小〜中 |
