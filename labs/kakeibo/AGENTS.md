# AGENTS.md

本ワークスペースは、YDE（Yaml Design Editor）用の家計簿のサンプルプロジェクト（試作）です。
`.tooldocs` にツールの使い方がある場合は、そのマニュアルに沿って YAML ファイルを作成・編集してください。

ツールそのものは含まれていないため、ツール起動による操作はできません。テストは不要です。

公開されるため、個人情報などのセンシティブな情報（実物の銀行明細など）は含めないでください。
`inbox/` の CSV は、銀行の公式サイトのサンプルと、それに合わせて作った架空のものです。

本ワークスペースの内容の詳細は `README.md` を、これからの整備の計画は `PLAN.md` を参照してください。
