# 家計簿の試作の引き継ぎ

新しいセッションで続きを頼むときは、次のプロンプトをそのまま貼ってください。

---

`labs/kakeibo` にある家計簿の試作の開発を続けてください。着手前に次を読んでください。

1. `labs/kakeibo/README.md`（構成・決めていること・検査とビュー・取り込み・わざと入れた食い違い・動かし方）と `labs/kakeibo/PLAN.md`（整備計画。段階と順番の案・判断が要ること）
2. `docs/manual/views.md`「値の式の列」と `docs/manual/checks.md`「パターン制約」の値の式（`all` / `each` / 配列を受け取る集計の書き方）
3. `docs/manual/ai.md`「行をひな型で組み立てて、配列へ追記する」（取り込み skill の `build` / `target.path` / `target.id` / `target.key`）
4. `docs/decisions/0010-expression-values-are-terms.md`（式の値は項・集合から値へは `all` だけ、の決定）

これまでに決まっていること（変えない）:

- 月はエンティティ（`M-YYYY-MM`）で、取引は `month` を参照で書く。年月を日付から切り出す式は足さない。
- 残高は手書きの期首残高と検査で守る。累計の列は作らない。不便なら「前月の期末残高を当月の期首に写す」組込みエージェントを検討する。
- 集計は `all` で集めて `sum` / `count` などの関数で畳む。古い書き方（集計の中の `of`、`count` に `match`）は定義エラーになる。
- 取り込みは追記と採番。行は変換定義のひな型（`build`）で組み立て、CSV の列は見出しの名前で指す（位置ではない）。同じ明細（`target.key`）は飛ばし、既存の明細は更新しない。費目は `CAT-UNSORTED` で入れて検査で警告する。
- 試作は `labs/` で作り、ある程度良いものができたら `samples/` へ置き直す。`samples/` へ移すかどうかはオーナーが決める。
- 新しいテーマや機能の着手はオーナーの判断。提案は出してよいが、指示を待つ。報告には試し方（操作手順と見てほしい観点）を添える。

済んだもの:

- 取り込み skill の採番（2026-09-28）: `.yde/skills/import-smbc.yaml`。三井住友銀行の公式サンプル CSV（`inbox/smbc-sample.csv`）を `book/tx/2021-08.yaml` へ取り込んである（費目は未分類のままで、警告 2 件）。
- 桁区切りの表示（2026-09-28）: 金額の項目とビューの合計の列に `display: grouped`。GUI の見せ方だけで、CLI の出力は元の数のまま。
- 明細の並び（2026-09-28）: ビューの `order` に `path` / `type` / `direction`。`.yde/views/transactions.yaml` が日付の新しい順。ID の形はそのまま（`TX-YYYYMMDD-NN`）。
- 両方の軸が動く表（2026-09-28）: クロス集計ビュー `kind: matrix`（旧 UX-135）。`.yde/views/month-by-category.yaml`（月×費目の金額）と `month-by-kind.yaml`（月×区分の件数）。月×費目（金額）の手書きの `monthly-sums.yaml` は、期末残高の列があるので残してある。オーナーの希望で、同じ表を「要素ごとに列を広げる」列（`each`）で書いた `month-by-category-b.yaml` も比較用に置いた。
- ビューグリッドの併記（2026-09-28）: 編集できない列の enum は「値（ラベル）」、参照は「ID（名前）」。編集できる参照のセルは入力欄の下に名前。

まだ手を付けていないもの（`PLAN.md` に段階と順番の案がある。以下はその要約）:

1. 月次の運用を一周させる: 取り込んだ取引の費目付け（摘要の言葉で当てる規則）・月初の手順を 1 操作に・予算と実績の対比・実物の CSV。
2. 見え方と検査を整える: 3 つある月×費目のビューの整理・検査の追加・クロス集計の細部。
3. `samples/` へ置き直す準備: 2021 年の取り込み結果を外す筋書き・検査の基準を守るテスト・文書。
4. 期首残高を写すエージェント: 上の決定のとおり、不便になってから。
5. 取り込みの派生: 費目の自動の割り当て（摘要のキーワードから。`$map` は完全一致だけなので、部分一致の語が要る）・年をまたぐ期間の CSV の年の取り違え・見出しの無い CSV（BACKLOG の UX-137）。

最初にやること: `./gradlew runCli -q --args="validate labs/kakeibo"` を実行し、README にある 5 件の指摘（エラー 2・警告 3）が出ることを確かめてから、オーナーに次に何を進めるか聞いてください。
