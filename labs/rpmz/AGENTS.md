# AGENTS.md

本ワークスペースは、YDE（YAML Design Editor）で RPG Maker MZ のデータベースを再現する試作です。
`.tooldocs` にツールの使い方がある場合は、そのマニュアルに沿って YAML ファイルを作成・編集してください。
リポジトリ内で `.tooldocs` がない場合は、ルートの `docs/manual/` を参照してください。

内容は `README.md`、これからの整備の計画は `PLAN.md` を参照してください。

## 決まり

- 項目名は MZ のデータ（`data/*.json`）のままにします。新しい項目を足すときも MZ の名前を使います。
- 番号（ID の数字）は MZ のデータベースの番号です。番号を付け替えると、MZ 側のイベントが番号で指しているものとずれます。
- GitHub で公開されるため、画像・音・動画・フォントなどの素材を置かないでください。素材の名前の項目は空のままにします。
- MZ の既定のデータベースの内容（名前・説明文・数値）を写さないでください。データはすべて架空のオリジナルにし、人名・地名は実在のものや既存の作品と重ならない造語にします。
- YAML とスキーマを直したら、`./gradlew runCli -q --args="validate labs/rpmz"` で検証してください（いまはエラー 0・警告 0）。
