# 本ツールで扱える範囲と不足

| 目的 | 現在の対応 |
|---|---|
| サービスの具体的な設計 | native Propertiesに合わせた型付きYAML。図用の別モデル・別の接続一覧は使わない |
| 設定の編集 | 1資源1文書のフォーム／ソース／差分、サービス別全設定表、参照ジャンプとUndo |
| 構成図 | flowの`sources`で複数文書をクエリ結合し、同じ原本から全体図と入口詳細図を作る |
| 図から設定を確認 | 単一原本のノードは原本フォームへ接続。結合した辺は各設定の来歴を保持 |
| 全設定の持ち出し | ビュー→TextTemplateによるパラメータ設計書。object・配列を省略せず掲載 |
| 意味的な探索 | lensで資源・Origin・Behavior・アプリ設定・配備先・運用手順の参照を辿る |
| 整合検査 | 参照、型、配備環境、ポート、スケール範囲、AZ、TLS／公開設定、TTL、Logical ID等を検査 |
| 生成工程への入力 | ResourceType・Properties・配備単位・属性付き参照を保持する4種類の変換 |

今回、本体に加えた汎用機能は**複数文書flowの入力`sources`**です。AWS専用の計算や書込経路は加えていません。
Queryで選択・結合し、Constructで表示へ写します。未保存変更・Undo・来歴・未解決参照・打切りの診断を既存の仕組みへ接続しました。

## 残る拡張

- **階層境界の図示**: Account→Region→VPC→AZ→Subnetを参照から重ねた枠へ射影する機能。現在のレーンは1段で、参照はレンズで確認する。
- **環境別の実効設定**: 共通設定とstg/prod差分を解決し、上書きの理由・来歴を表示する仕組み。このラボは本番の具体値と外部入力を扱う。
- **CFn生成**: 動的なmapキー、属性の束縛、Stack境界、依存循環、出力スキーマと配備前検査。詳細は[生成契約](GENERATION.md)。
- **名前付きlensの範囲**: 起点・対象型・展開範囲を再利用できるビュー定義。現状は利用者が画面で範囲を選ぶ。
- **縦型のパラメータシート**: 一つの資源の入れ子設定を「項目パス×値×理由×既定値との差」の行へ汎用的に展開する表示。現状は全設定のフォーム、サービス別の横表、全項目の設計書を提供する。
- **図のアクセシビリティ**: Canvas上のノード選択を意味ツリーへ公開する機能。現状のMCPによる画面確認は、図の選択・配置完了・周辺操作まで。

AWSのCIDR計算、実効IAM権限、クォータ、利用可能な版・リージョン等は一般的な参照検査だけでは判断できません。
構造・参照検査の成功と、AWS上での動作確認を分けています。
