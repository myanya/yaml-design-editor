YAML Design Editor — Windows x64 ZIP 版

使い始める
1. ZIP を「すべて展開」し、フォルダ一式を取り出してください。
2. yaml-design-editor.exe をダブルクリックします。Java の追加インストールは不要です。
3. 「ワークスペースを開く…」から、編集するフォルダを選択してください。
展開時にパスが長すぎると表示された場合は、浅い階層のフォルダへ展開してください。

初めて試す場合
サンプルを見るなら、examples/todos をドキュメント等の作業用フォルダへコピーし、コピーした todos を開いてください。
todos/todo-list.yaml を開き、タイトルを変更して Ctrl+S で保存し、開き直して内容を確認できます。
自分の情報を管理するなら、スタート画面の「新しいワークスペースを作る…」から始めてください。
テンプレート（課題管理）か、自分の項目（管理するものの名前・ID の接頭辞・項目）に答えると、定義一式ができて開きます。
ツールバーの「?」から利用者マニュアルを開けます。サンプルの詳細は examples/todos/README.md にあります。
AI 機能の利用は任意です。通常の編集・保存に API キーは不要です。

更新とデータの保管
アプリを終了し、新版 ZIP を別のフォルダへ展開して起動してください。自動更新機能はありません。
ワークスペースはアプリのフォルダ外に保存し、更新前にバックアップしてください。
app と runtime は exe と一緒に保管してください。これらを取り除くと起動できません。
履歴や画面設定は Windows のユーザー設定にも保存されます。設定まで含めた完全なポータブル版ではありません。
削除するときはアプリを終了し、展開したアプリフォルダを削除します。ユーザー設定は別途残ります。

利用上の前提
自分で作成した、または内容を確認したワークスペースを開いてください。
既知の制約はアプリ内ヘルプの「既知の制約」を参照してください。
この ZIP は未署名です。Windows が発行元や評判に関する警告を表示する場合があります。
入手元と公開されたチェックサムを確認してください。セキュリティ機能の無効化は不要です。

版とライセンス
BUILD-INFO.txt にアプリの版とビルド元コミット、RUNTIME-RELEASE.txt に同梱 Java の情報があります。
本体・依存ライブラリ・フォントの表示は app/resources/licenses/、Java の表示は runtime/legal/ にあります。
問題の報告では、アプリの版・Windows の版・再現手順を添え、API キーや業務データは掲載しないでください。
