# todos-generated

詳細設計の確定設定から生成した、独立した Spring Boot プロジェクトです。
物理テーブルの Java 行モデル、Mapper と XML、DB の初期作成、状態型と業務例外、全操作の Service、入力検査付き Form、デザイン台帳からの CSS と確認画面を生成します。業務の一覧・詳細・確認・確定をつなぐ Controller は後続です。

同時更新の方式は `local-serialized` です。アプリ共通の `OperationRunner` が、採番前からトランザクションの確定・取り消しまで順番を保ちます。
操作は既存のトランザクションの外から呼びます。複数アプリから同じ DB を更新する構成には対応していません。

## ビルドと起動

Java 21 を用意し、このフォルダで実行します。依存関係の初回取得にはネットワークが必要です。

```powershell
.\gradlew.bat test bootJar
java -jar build/libs/todos-generated.jar
```

macOS・Linux では `sh ./gradlew test bootJar` を使います。
待受ポートは 8085、DB は作業ディレクトリ内の `data/todos` に保存します。
終了は起動した端末で Ctrl+C。別のポート・DB は Spring Boot の起動引数で指定できます。
空の DB には `schema.sql` を適用します。既存 DB に必要なテーブルがあれば、そのまま使います。
必要なテーブルが欠けていれば起動を止めます。既存テーブルの列や制約の変更・移行は未対応です。設計変更の検証には別の DB 名を指定してください。

このフォルダだけを別の場所へコピーしても同じ手順でビルドできます。YDE や親の Gradle 設定は不要です。
生成物を直す場合は設計の入力か生成規則へ変更を戻して再生成します。

## 画面デザインの確認

起動後に `http://localhost:8085/design-preview` を開きます。
ゲーム風のサイバーパンクの配色・入力欄・通知・一覧の部品を確認できます。
タイトルを空にする、または 101 文字にして「入力検査を試す」を押すと、確定したフォームの制約と日本語の文を確認できます。
この画面は DB を更新しません。画面幅を狭めた場合と Tab キーでの移動も確認してください。
業務画面は未接続のため `/` は 404 です。
