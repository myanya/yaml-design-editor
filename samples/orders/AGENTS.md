# AGENTS.md

本ワークスペースは、YDE（YAML Design Editor）用の注文管理のサンプルです。
`.tooldocs` がある場合は、そのマニュアルに沿って YAML ファイルを作成・編集してください。
リポジトリ内で `.tooldocs` がない場合は、ルートの `docs/manual/` を参照してください。

単独配布時はツール本体を含みません。リポジトリ内での作業はルートの AGENTS.md に従い、同梱 CLI で検証できます。
サンプル専用のテストコードや実行環境は追加しません。YDE の検証と README の試用手順で確認してください。

注文管理のモデルは `.yde/` の型・検査・操作・ビュー・レポートで定義し、具体的なデータは `orders/`・`customers/`・`companies/`・`categories/`・`products/` に置きます。
業務上の意味は定義の `description` と README で説明します。

GitHub 上で公開されるため、個人情報などのセンシティブな情報は含めないでください。顧客・会社の名前や連絡先は架空のものです。
データを足すときも同じ決まりにしてください。会社名は実在しない造語、住所の番地は `X-X-X`、電話番号の中央 4 桁は `0000`、法人番号は先頭 `0`、メールアドレスは `example.*` のドメイン。

本ワークスペースの内容の詳細は、`README.md` を参照してください。
